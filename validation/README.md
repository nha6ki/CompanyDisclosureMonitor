抽出結果を見た後の選び直しは行っていません。別企業への拡張ではなく、NVIDIAの中での追加確認です。

## 結果

| 2026-04-27 | 最高会計責任者の交代 | 退任意向・発効条件の2候補 |

5件の本文を取得し、2件から計4候補を抽出しました。4候補は原文に存在し、候補ラベルが
段落の内容に対応することをChatGPTが確認しました。ただし短い断片であり、氏名・日付・条件などの
重要な情報が抜ける場合があります。候補を得られた比率は要約の正解率や網羅率ではありません。

取りこぼした3件の原因は、Item未対応・出来事未対応・言い回しへの依存です。
特にItem 5.07が返されないのは、見出しの対応表にないためです。本文にその項目がない、あるいは
SECの登録が誤っているという意味ではありません。

## 再実行

親ディレクトリの `extract_evidence.py` を、そのまま呼び出します。
コードのSHA-256が検証時と異なる場合は停止します。

```bash
python validation/run_validation.py --source-dir /path/to/validation-cache
```

原文がない場合は、対象5件をSECから取得できます。

```bash
python validation/run_validation.py --fetch --contact your-address@example.com
```

キャッシュは `validation/cache/<提出番号>/primary.html` に作成します。再実行は
`python validation/run_validation.py` です。連絡先を環境変数 `SEC_CONTACT_EMAIL` で指定することもできます。
通信間隔・エラー停止・本文ハッシュの扱いは親ディレクトリのREADMEと同じです。
再取得した原文が検証時と変わっていれば、その資料を内容評価に含めません。

出力は `validation/output/nvidia_additional_five_validation.html` と `results.json` です。
今回の終了コードは `2` です。3件が「候補なし」だったことを示し、通信障害ではありません。

## 記録

- `selection.json`：選定対象と変更前の抽出コードのハッシュ。
- `review_plan.json`：先に定めた確認項目。
- `source_manifest.json`：取得日時・URL・本文ハッシュ。
- `manual_review_before_run.json`：処理実行前に原文を読んで記録した主要内容。
- `assessment.json`：実行後に原文と比較した定性的な所見。
- `output/results.json`：実行結果。抜粋の位置と段落ハッシュを含みます。

要約・所見はChatGPTによる確認です。外部の独立した評価者による評価ではありません。
抽出ルールは変更していません。今後この5件を使ってルールを修正した場合、その改良版について
同じ5件を未知の検証資料として扱うことはできません。
